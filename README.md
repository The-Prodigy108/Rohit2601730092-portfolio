# My Personal Portfolio 🌐

Hello! I'm **Rohit Kumar**, a first-year B.Tech student interested in programming, web development, AI and IoT.

This is my personal portfolio website, which I created while learning HTML and CSS. It contains information about me, my skills, projects and contact details.

## 📌 About the Project

The main purpose of this project is to practice HTML and CSS and learn how to create a simple, responsive website.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## ✨ Features

- Home section with my introduction and profile picture.
- About Me section.
- Skills section showing my current technical skills.
- Projects section displaying some of my work.
- Contact form.
- LinkedIn and GitHub links.
- Responsive design for mobile and desktop screens.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all the files are in the same folder.
4. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code to run the website.
